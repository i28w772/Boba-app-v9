Boba AI providers
Boba AI can run on Claude, OpenAI, Gemini, Grok, a local Ollama server, or any OpenAI-compatible endpoint — bring your own API key. Keys are stored only in this browser's local storage and sent directly to the provider you choose, never to any server of ours. Anyone with access to this device could read a key from local storage, so use keys you're comfortable having client-side, ideally with a spend limit set.

Backup & restore
Everything in this app — notes, favorites, calendar, browser bookmarks/history, watch history, search history, AI chat, and your settings/keys — lives only in this browser's local storage. There's no account and no cloud sync, so clearing your browser data or switching devices loses it all unless you back it up here first.
Made with 🧋 · Location via the Geolocation API · Map by Leaflet & OpenStreetMap · Weather by Open-Meteo · Shops via OpenStreetMap Overpass (or Google Places if you add a key) · Notes, favorites & events saved in your browser's local storage.
